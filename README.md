# GIT Chinese Trainer AI

Ứng dụng PWA luyện tiếng Trung HSK: luyện gõ chữ Hán, dịch nghĩa tiếng Việt, Pinyin, phát âm Mandarin (Web Speech API), thống kê và trợ lý học tập.

## Triển khai V2

Mã nguồn đầy đủ được đóng gói trong `GIT-Chinese-Trainer-AI-UI-v2.zip` ở cuộc trò chuyện ChatGPT. Giải nén rồi tải **nội dung bên trong** lên nhánh `main` của repository này, giữ nguyên cấu trúc thư mục `css/`, `js/`, `data/`, `icons/`, `.github/workflows/` và các tệp gốc. Sau đó bật GitHub Pages: Settings → Pages → Source: GitHub Actions.

## Bảo mật

Không đưa API key AI vào JavaScript hoặc GitHub Pages. Chỉ kết nối AI thực thông qua backend HTTPS bảo mật.
